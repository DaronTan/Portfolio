Project Description

This game was made in Unity for gameplay using C# & used Firebase for data storage features.


The project was a solo project incorporating Firebase to make games more interactive and interesting.


Gameplay

The player clicks on orbs to accumulate score and accuracy.


Orbsolete has 2 different gamemodes with 3 levels of difficulty; normal & endless with difficulty ranging from easy, medium to hard.


Normal gamemode has a set timer of 60 seconds for players to accumulate scores.


Endless gamemode has no timer and players can keep playing endlessly to accumulate scores until they lose.


Players can win by completing the 60 seconds on normal gamemode while endless players can only lose by either getting a negative score or missing an orb before it despawns.


Firebase Usage

This project was made experimenting with Firebase authentication, and realtime database.


Players can sign-in with an account, track and see their statistics as well as leaderboard that displays realtime scores.


Some statistics players can see are total score, accuracy, highest score and account creation dates.
